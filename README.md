# Screenshot Reader

A desktop OCR application built with **C++ and Qt**, powered by **Tesseract OCR** for extracting text from images.

> **Status:** In Development

The application allows users to load an image, recognize the text contained in it, and view the extracted text directly in the application.

## Features

* Text recognition from images
* OCR powered by Tesseract
* Russian language support
* English language support
* Image loading
* Display of recognized text
* Qt-based desktop interface
* Local image processing



## Technologies

| Technology    | Purpose                       |
| ------------- | ----------------------------- |
| C++           | Core application language     |
| Qt 6          | Graphical user interface      |
| Tesseract OCR | Optical character recognition |
| Leptonica     | Image processing              |
| CMake         | Build system                  |




### Requirements

* C++17 or later
* Qt 6
* CMake
* Tesseract OCR
* Leptonica
